# Upgrade an existing backup to the v0.30 development branch

These steps apply to an existing kei installation. If you're installing the released v0.26.0 binary, use its [upgrade guide](v0.26.0-upgrade.md) instead.

1. Stop every writer, including watch processes, background services and containers. Make a matched cold backup of your configuration, complete data directory and media tree, including sidecars and hidden history. This branch opens SQLite state at schema 44. To roll back, stop kei and restore the matched pre-upgrade backup before starting the older binary. Copying back just the executable or lowering the database version is not a rollback.
2. Work on a copy of your config. Follow the [rendition-policy migration](rendition-policy-migration.md) before adding `config_version = 1`. Review the edits, RAW/JPEG renditions and Live Photo components that your first sync can download. If you previously used `edited_naming = "primary"`, see [edited filenames and existing layouts](edited-primary.md).
3. Check service arguments as well as TOML. Remove `--recent`, `--recent-scope`, `[filters].recent` and `[filters].recent_scope` from sync and service configurations. If you want a sample, set inclusive `skip_created_before` and `skip_created_after` dates such as `2025-01-01` and `2025-01-07`; choose dates from your own library. Removing a count limit without replacing it can select much more media. `import-existing --recent N` still samples by count.
4. Review `kei config show --config /path/to/config.toml`, then run `kei sync --config /path/to/config.toml --dry-run`. Check the selected libraries, albums, date range and destination before running the same sync without `--dry-run`. Keep the cold backup: a preview is not a substitute for it.
5. Run `kei status` against the same configuration and open a few downloaded files. Run ordinary `kei sync` again for unfinished work. If one existing file looks damaged, follow [Backup maintenance](backup-maintenance.md) to inspect that copy before authorizing replacement. A successful sync does not verify every historical file.
